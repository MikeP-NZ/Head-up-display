    Boat network

    The Wi-Fi network of your Yacht Devices gateway (or the boat router it is joined to).

    Setup access point

    The display's own Wi-Fi network for this page, at http://192.168.71.1. On the boat network the page is also at http://headup.local.

    Demo mode

    Shows a simulated sailing boat beating to windward, so the display can be demonstrated without instruments or a gateway. It tacks every 3 minutes, swinging about 45° either side of the wind, so the apparent wind changes sides. The panel flashes SIMULATED DATA over the values every 5 seconds, and the gateway connection is paused while it runs.

    Gateway data port

    Where the display reads NMEA data from. Factory setting on Yacht Devices gateways: Server #1, TCP, port 1456, NMEA 0183.

    Network protocol
    Data protocol
    Must match the server's «Data protocol» in the gateway. Auto accepts both.
    Setting up the gateway's server port
    1. Join the gateway's Wi-Fi with a phone and open http://192.168.4.1 (login admin / admin unless changed).
    2. Open NMEA Server. Enable a server, choose TCP or UDP and a port, and set its data protocol to NMEA 0183 or RAW.
    3. Prefer UDP if chart-plotter apps also use the gateway: a TCP server only accepts 3 connections, and UDP has no limit.
    4. For NMEA 0183, check that the transmit filter lets through the sentences for the values you want: VHW (speed through water, heading), RMC/VTG (GPS speed and course), MWV (wind), MWD (wind direction), HDG/HDM (heading), DPT/DBT (depth), RMB/BWC (waypoint distance and bearing) and VPW (VMG) and MTW (water temperature).
    5. RAW carries the NMEA 2000 messages directly (PGN 128259 speed, 129026 GPS speed and course, 130306 wind, 127250 heading, 127258 variation, 128267 depth, 129284 waypoint, 130310/130311/130312/130316 water temperature), so no filters are involved. VMG to wind has no standard NMEA 2000 message; the display can calculate it (Data tab), or use NMEA 0183 VPW.

    Item Display

    Boat speed, true wind and VMG

    STW is speed through water (paddle wheel/log), SOG is speed over ground (GPS). The speed source picks which one the Boat speed item shows, and which one the calculations use: TWA and TWS are worked out from the apparent wind (AWA, AWS) and that speed, TWD adds the heading, and VMG is the speed times cos(TWA).

    Default magnetic variation
    Used for true/magnetic conversions while no variation is received. Leave empty if your GPS sends it.

    Source device

    With more than one speed sensor or GPS on the bus, pick which one to trust. NMEA 2000 devices appear by source address with RAW, and as talker IDs with NMEA 0183.

    Layout

    Split the panel into sections, each showing one value. Changes apply to the panel immediately.

    Sections
    Wind angles show 0–180° with <<< (port, red) or >>> (starboard, green); << / >> in sections. Headings, course, bearing and wind direction are true or magnetic as set on the Data tab. Short distances show as whole numbers. Sections without data show dashes.

    Appearance

    Changes apply to the panel immediately.

    Night mode

    Dim, single-colour display to keep night vision. A short press of the BOOT button toggles it.

    Tools

    The test pattern cycles red, green, blue and white, then colour bars with a marker in the top-left corner. Use it to check the Hardware settings.

    LED panel hardware

    Changes need a reboot.

    Clock phase
    SM16380 panels need this unticked: ticked gives vertical ghosting and white blocks of columns.

    Output connector

    The four HUB75 outputs work in pairs: X1 and X3 share data lines, and so do X2 and X4. A pair can drive two panels with the same image, for example back-to-back so the speed reads from both sides. To add panels, chain them from the connector you use.

    HUB75 pins (GPIO)

    Pre-set for this board. Only change them for custom wiring.
